# Security policy

## Reporting a vulnerability

Please report security issues in the Volo smart contracts through our bug bounty programme on
HackenProof: https://hackenproof.com/programs/volo-smart-contracts

The programme publishes the reward tiers, the triage and response SLA, and the disclosure
guidelines that apply to every report.

Security contact: Bounty Team — bounty@naviprotocol.io

Do not open a public GitHub issue for a vulnerability.

## Scope

The packages in this repository as deployed on Sui mainnet. Deployed package ids and versions are
listed in the [README](./README.md); each package's `Published.toml` records its deployed version.

## Coordinated disclosure

We ask reporters to give us the time stated in the programme's disclosure guidelines to triage and
fix an issue before any public disclosure. We acknowledge valid reports through the programme and
credit reporters there unless they prefer otherwise.
